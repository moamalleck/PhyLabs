# PhysicianLabs — Marketing Message Test
**Created:** 2026-06-25
**Owner:** Founder
**Status:** Active test — log results after each campaign / posting run
**Purpose:** A/B test five distinct messaging hooks (≤140 chars) to find which *idea* converts, then double down.

---

## How to Use This Document

Each message tests a **distinct angle and vocabulary** so the winner tells you which *concept* resonates,
not just which wording. Run them in comparable conditions (same channel, similar audience, similar time)
and log the numbers in the tracker below.

- **CTR = Clicks ÷ Impressions.** Primary signal for hook strength.
- **CVR = Conversions ÷ Clicks.** Did the click turn into a booked diagnostic / reply / sign-up?
- Keep messages running until each has **≥1,000 impressions** (or ≥100 on a small warm list) before calling a winner.
- Strike through losers; promote the winner's *concept* into landing-page and pitch copy.

## The Messages

> All ≤140 characters. Copy-paste ready.

### M1 — Money-back / revenue-leak hook · 112 chars
```
We find $20K you're not collecting—or it's free. Just went independent? Stop leaking revenue you already earned.
```
**Angle:** the guarantee + loss aversion. **Core concepts:** $20K, money-back, "revenue you already earned."

### M2 — Visibility / windshield hook · 111 chars
```
Your EHR is a rear-view mirror. PhysicianLabs is the windshield—see where your practice is headed in real time.
```
**Angle:** foresight vs. hindsight. **Core concepts:** windshield vs. rear-view, real-time, EHR contrast.

### M3 — Clinical-credibility hook · 112 chars
```
Denied claims. Under-coded visits. Underpaid contracts. Your billing hides five figures—we surface every dollar.
```
**Angle:** domain specificity + traceability. **Core concepts:** the 4 leak sources, "five figures hiding."

### M4 — Founder-fear hook · 114 chars
```
16 years training to practice medicine. Zero hours to run the business. Don't lose $200K finding out the hard way.
```
**Angle:** the training gap + cautionary story. **Core concepts:** 16 years, $200K loss, "the hard way."

### M5 — Identity / admin-burden hook · 120 chars
```
You went solo to treat patients—not to live in spreadsheets. See your whole practice in one place. Founding clinics now.
```
**Angle:** professional identity + scarcity. **Core concepts:** spreadsheet fatigue, "one place," founding-clinic scarcity.
