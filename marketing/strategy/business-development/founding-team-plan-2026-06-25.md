# PhysicianLabs — Founding Team Plan & Role-Gap Audit
**Created:** 2026-06-25
**Owner:** Ash Malleck (Founder & CEO)
**Status:** Working plan — update as co-founder/advisor conversations progress
**Purpose:** Turn the team-building research into a concrete plan: who we have, the critical gaps, a co-founder
scorecard, a hire/advisor sequence, and what investors need to see on the team slide.

> Why this matters: across the source material, **~70% of an early-stage investment decision is the team**
> (Suster), and **~65% of startups fail from team/management issues, not product** (MassChallenge). Investors
> want a well-rounded, complementary, aligned founding team — not a solo founder.

---

## 1. Principles we're operating on (from the research)

| Principle | Source | How we apply it |
|---|---|---|
| Founder ≠ Founding Team ≠ Founding CEO | Blank (Medium) | Ash is founder + founding CEO today; the *founding team* is still being assembled. |
| **Co-founder test:** "Do we have a company without them?" + "Can we find someone else like them?" — both *no* = true co-founder | Blank (Medium) | Apply to every candidate before granting co-founder equity. |
| Relationship > résumé; **must have worked together first** | Medium / Calacanis | No equity grant without a paid trial project or prior working history. |
| Complementary trio: hacker / hustler / designer; 2–4 people | Medium / FI | Map each seat (below) and fill what's missing. |
| Stay tech- & product-heavy; don't outsource core product; don't over-hire business before PMF | Suster | Concierge runway now; technical co-founder before the SaaS build. |
| Don't take on too many co-founders ("most expensive dilution") | Suster | Target **1** technical co-founder, not a crowd. |
| Audit your own gaps and recruit for what you lack | FI | See §2. |
| Early hires take more risk → more equity; advisors worth equity at ~1 hr/mo, ~50 hr/yr | Carta / Calacanis | Drives §4 comp and §5 advisor plan. |

## 3. Co-founder scorecard (use before any equity conversation)

Score each candidate 1–5. A true co-founder should clear the gates *and* score well.

| Criterion | Weight | Candidate A | Candidate B |
|---|---|---|---|
| **Gate: "No company without them?"** (yes required) | gate | | |
| **Gate: "Can't easily replace them?"** (yes required) | gate | | |
| Complementary skill (fills a 🔴 gap above) | High | | |
| Builder track record (shipped real product) | High | | |
| Prior working relationship / trial completed | High | | |
| Aligned on mission (revitalize independent medicine) | High | | |
| Work-style fit (pace, conflict, ambiguity tolerance) | Med | | |
| Resilience / agility / curiosity | Med | | |
| Comfortable wearing many hats ("not my job" = red flag) | Med | | |
| Runway commitment (full-time, risk-tolerant) | Med | | |

> Decision rule: fails a gate → hire later as an employee, not a co-founder. Passes gates + high score →
> run a 2–4 week paid trial project before finalizing equity.

## 4. Hire & equity sequence

1. **Now (concierge phase):** no engineering hire needed — Ash delivers the manual revenue-leak audit. Buys
   runway and keeps dilution at zero while validating WTP.
2. **Pre/at seed:** recruit the **technical co-founder (CTO)**. Expect to trade meaningful equity for an
   early, risk-tolerant builder (Carta: first hires take more risk → more equity). Run a paid trial first.
3. **Post-seed (after a reasonable round):** first functional hires — Ops/VP Finance to free Ash from admin
   (Suster), then sales/CS as the $599/mo motion scales.
4. **Guardrail:** keep the co-founder count small. Cap equity-bearing co-founders at the seats that pass the
   Blank test (target: 1 technical co-founder).
